01 / REGISTER

Choose a quest

One pending submission per quest and wallet. Maximum three attempts. A passing wallet cannot submit again for the same quest.

02 / PUBLISH

Bind evidence to your wallet

Publish the downloaded file in a public GitHub repository. Open the file at its commit, select Raw, and paste the URL below. The URL must include the full 40-character commit SHA, not main. Your file is public.

03 / REVIEW

Ask validators, not a checkbox

The contract fetches evidence, checks the wallet challenge and stores its SHA-256 digest. AI judges all quest requirements against the actual text. No operator can manually force a PASS.

04 / CLAIM

Claim contribution points

Only a PASS can earn points. The contract updates a public, non-transferable score ledger; it does not pay GEN or another asset.

What the proof means

Verified by design: the submitting transaction came from the recorded wallet; the pinned file contains its contract-specific challenge; validators assess the published text against the quest rules.

Not claimed: legal identity, ownership of a GitHub account, originality across the entire internet, human uniqueness, guaranteed AI accuracy, or financial rewards. Public challenges are not secret. Studionet is a development environment that can reset.
